### Broker 强杀步骤

1. 应用测试下单，保存 Outbox；worker 调真实 Broker 发送 45 秒后的消息。
2. 测试断言 `sent=true` 后写入 ready 标记；此时订单仍为 PENDING。
3. 确認对应独立 Proxy/Broker PID 后执行 SIGKILL，并以同一配置、同一存储目录重新启动。
4. 原消费者恢复连接，延时消息驱动同一 `OrderTimeoutHandler` 关闭订单。
5. 再发送同 eventId、同原始 deadline；Spy 验证 Handler 实际调用至少 2 次；最终 amount=5、frozen=0。

测试没有启用数据库定时扫描，因此该场景的关单确实由 MQ 消费触发。
