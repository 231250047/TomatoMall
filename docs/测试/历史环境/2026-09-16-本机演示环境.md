## 启动命令记录

以下命令用于进程已经停止后的重启；不要重复启动占用同一端口的服务。每个服务占用一个终端。前提是临时文件仍然存在。

```sh
# 独立 MySQL（不是默认 3306 实例）
/opt/homebrew/opt/mysql@8.0/bin/mysqld --no-defaults --datadir=/private/tmp/tomatomall-mysql-isolated --port=33077 --bind-address=127.0.0.1 --socket=/private/tmp/tomatomall-mysql-isolated/mysql.sock --pid-file=/private/tmp/tomatomall-mysql-isolated/mysql.pid --log-error=/private/tmp/tomatomall-mysql-isolated/mysql.log --mysqlx=OFF

# Redis
/private/tmp/tomatomall-demo/redis-7.4.2/src/redis-server --bind 127.0.0.1 --port 16379 --dir /private/tmp/tomatomall-demo --dbfilename demo.rdb --appendonly yes --logfile /private/tmp/tomatomall-demo/redis.log

# NameServer
/Users/changhan.6/Library/Java/JavaVirtualMachines/ms-17.0.20/Contents/Home/bin/java -Xms128m -Xmx512m -Duser.home=/private/tmp/tomatomall-rmq-runtime -Drocketmq.home.dir=/private/tmp/tomatomall-rocketmq/rocketmq-all-5.3.2-bin-release -cp '/private/tmp/tomatomall-rocketmq/rocketmq-all-5.3.2-bin-release/lib/*' org.apache.rocketmq.namesrv.NamesrvStartup -c /private/tmp/tomatomall-rmq-runtime/namesrv.conf

# Broker + Proxy，NameServer 就绪后启动
/Users/changhan.6/Library/Java/JavaVirtualMachines/ms-17.0.20/Contents/Home/bin/java -Xms256m -Xmx768m --add-opens=java.base/java.nio=ALL-UNNAMED --add-opens=java.base/sun.nio.ch=ALL-UNNAMED -Duser.home=/private/tmp/tomatomall-rmq-runtime -Drocketmq.home.dir=/private/tmp/tomatomall-rocketmq/rocketmq-all-5.3.2-bin-release -cp '/private/tmp/tomatomall-rocketmq/rocketmq-all-5.3.2-bin-release/lib/*' org.apache.rocketmq.proxy.ProxyStartup -pm local -bc /private/tmp/tomatomall-rmq-runtime/broker.conf -pc /private/tmp/tomatomall-rmq-runtime/proxy.json

# 后端
cd /Users/changhan.6/Documents/word/TomatoMall/tomatoMall-backend
/Users/changhan.6/Library/Java/JavaVirtualMachines/ms-17.0.20/Contents/Home/bin/java -Xmx768m -jar target/TomatoMall-0.0.1-SNAPSHOT.jar --spring.config.location=file:/Users/changhan.6/Documents/word/TomatoMall/tmp/local-demo/application.properties

# 前端
cd /Users/changhan.6/Documents/word/TomatoMall/tomatoMall-frontend
/Users/changhan.6/.nvm/versions/node/v22.22.3/bin/node node_modules/vite/bin/vite.js --host localhost --port 5173 --strictPort
```

前台运行时可以在对应终端按 Ctrl+C 停止。停止当前后台进程前，先通过 `lsof -nP -iTCP:端口 -sTCP:LISTEN` 确认 PID 和命令，只停止对应演示进程；不要使用按进程名批量结束的命令。
