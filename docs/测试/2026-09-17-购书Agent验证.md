## 16条真实端到端原话评测

数据：独立MySQL的100件合成商品、99条有效向量；text-embedding-v4，1024维。请求模型deepseek-v4-flash；路由原生tools、temperature=0、max_tokens=700、非思考模式；推荐选择保留既有4096输出预算。实际响应模型名及token记录在逐题诊断。

请求只包含用户原话 `{"query":"Java入门书，50块以下"}`。**没有把题库中的maxPrice、目标ID或预期路由发送给接口。** 题库在真实模型运行前冻结，哈希见[manifest](结果/rag/2026-09-17-shopping/manifest.json)。它是开发者编写的回归集，不是独立真实用户盲测。

| 指标 | 实际结果 | 含义 |
| --- | --- | --- |
| 路由正确 | 16/16 | 包含规则直接查询/澄清，不能全部归功于模型 |
| 有标注目标题命中 | 7/7 | 命中至少一个目标，不代表所有推荐都完美 |
| 超预算查询 | 0 | 按实际回答价格检查；无结果不能单凭该指标算质量成功 |
| 无匹配/澄清/问候/价格列表响应检查 | 8/8 | 按预先定义的行为核对 |
| 工具选择模型调用 | 8次 | 其余题走确定性路径 |

**边界：** b11“余华风格”只评估路由和价格，没有完备风格相关标签，不能计入风格准确率。b10作者查询为空，因为合成库没有可靠余华著作记录；作者字段正例与“研究作者”负例由单元测试覆盖，真实作者查询效果尚未验收。

结果采集于预算话题误判修复之前；之后只收紧两项误判并增加回归测试，既有16题条件不变。manifest分别记录评测JAR与最终运行JAR哈希。最终部署另做原聊天入口冒烟，不将两个版本混称同一次模型实验。
