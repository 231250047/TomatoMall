# RAG 阶段一：无匹配与模型异常修复

范围：用户已确认先完成无匹配处理、空响应诊断和回归验证。查询理解、相关性重排和 Agent 工具路由属于后续阶段。

## 验收规则

- 检索为空：返回未找到商品，不调用 LLM。
- 模型合法返回 items=[]：只说明本次候选不够匹配，不回填候选，也不声称整个商城绝对没有该商品。
- 模型返回正常选品：沿用 ID 白名单、引用验证、实时商品事实检查。
- 调用异常、空正文、截断或非法输出：明确推荐暂不可用，不将未经相关性复核的候选直接推荐。
- 模型调用记录安全元信息：请求／响应模型、结束原因、HTTP 状态、token 用量、耗时和分类结果；不记录提示词、完整响应、推理文本、密钥或异常正文。
- 先复现失败用例，再通过完整回归与真实模型抽样复查。保留此前首次评测，不覆盖历史成绩。
