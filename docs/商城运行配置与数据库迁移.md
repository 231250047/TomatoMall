# 商城运行配置与数据库迁移

适用于 Windows、macOS、Linux 开发环境。更新：2026-09-17。以下端口为本文的统一示例，已有环境按实际地址修改。

## 1. 运行依赖

**Spring AI 1.0.0-M4 是 Java 库版本，不限制操作系统。** M4 表示里程碑版本；保留它是为了兼容现有代码，与 Mac 无关。Windows 使用 JDK 17 和 Maven 即可编译同一项目，不需要修改业务代码。

| 依赖 | 项目使用版本 | 用途／示例端口 |
| --- | --- | --- |
| JDK / Maven | Java 17 / Maven 3.9.x | 编译与运行 Spring Boot 3.2.4，后端8080 |
| Node.js / npm | Node 22.x，附带npm | Vue 3 / Vite 6，前端5173 |
| MySQL | 8.0.x | 商品、用户、订单等业务数据，3306 |
| Redis | 7.4.x | 展示缓存，6379 |
| RocketMQ | 5.3.2 | 订单超时与商品变更消息；NameServer9876、Proxy8081 |
| **PostgreSQL + pgvector** | **PostgreSQL 16 + pgvector 0.8.0** | **新增：向量持久化，宿主机15432** |
| DashScope / DeepSeek | API服务 | 商品向量生成／推荐回答，需要各自的有效密钥 |

新增 Java 依赖已写入 [pom.xml](../tomatoMall-backend/pom.xml)：`org.springframework.ai:spring-ai-pgvector-store:1.0.0-M4`、`org.postgresql:postgresql`（驱动版本由Spring Boot管理）。Maven会自动下载，无须手动复制JAR。PostgreSQL和pgvector需要单独部署，Maven不会替你安装数据库。

Windows建议安装 [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/)，启用WSL 2与Linux容器，用容器运行Redis、RocketMQ、pgvector；Java、Maven、Node和MySQL客户端可安装在Windows本机。pgvector也支持原生安装，参见 [官方说明](https://github.com/pgvector/pgvector)。这些Windows命令未在Windows机器上实测，项目代码与依赖不限定Mac。

## 2. 配置文件

复制 [application-example.yml](../tomatoMall-backend/src/main/resources/application-example.yml) 为同目录 `application.yml`（Git已忽略），在IDE中填写配置；可以直接把 `${...}` 表达式替换为实际值，也可以设置对应环境变量。所有没有默认值的占位符都需要提供值，未启用的外部服务可先填占位值，其功能不可用。密钥、密码不提交Git。

| Spring属性 | 填写内容 |
| --- | --- |
| `spring.datasource.url` | `jdbc:mysql://127.0.0.1:3306/tomatomall_demo?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai` |
| `spring.datasource.username` / `password` | 目标MySQL用户名／密码 |
| `spring.jpa.hibernate.ddl-auto` | 已导入匹配结构的库使用`validate`；不要把历史SQL当作当前结构 |
| `spring.jpa.open-in-view` | `false`，避免远程模型调用期间保留请求级JPA上下文 |
| `spring.data.redis.host` / `port` | `127.0.0.1` / `6379`；多套环境另配`database`或独立实例 |
| `orders.mq.enabled` / `orders.mq.endpoints` | `true` / `127.0.0.1:8081`（连接Proxy，不是NameServer） |
| `orders.mq.topic` / `consumer-group` | `order-timeout` / `order-timeout-consumer` |
| `server.port` / `orders.frontend-url` | `8080` / `http://localhost:5173` |
| `aliyun.oss.file.endpoint` / `keyid` / `keysecret` / `bucketname` | OSS区域Endpoint、访问密钥和Bucket；用于图片上传 |

### 向量检索与AI新增配置

| Spring属性 | 填写内容 |
| --- | --- |
| `rag.retrieval.min-similarity` | 普通检索向量路阈值，默认 `0.54`，范围 `[0.3,1]`；更换模型须重新评测。推荐候选召回使用 `0.3` 后交模型筛选 |
| `rag.vector.enabled` | 启用向量检索填`true`；不启用时使用关键词降级 |
| `rag.vector.url` | `jdbc:postgresql://127.0.0.1:15432/tomatomall_vectors` |
| `rag.vector.username` / `password` | PostgreSQL用户名／密码，与MySQL独立 |
| `rag.vector.namespace` | 源商品库标识，例如`tomatomall_demo`；不同商品库使用独立向量库 |
| `aliyun.dashscope.api-key` | DashScope API Key，用于Embedding |
| `aliyun.dashscope.embedding.model` / `dimensions` | `text-embedding-v4` / `1024`，必须与SQL中的`vector(1024)`匹配 |
| `spring.ai.openai.api-key` | 当前推荐服务使用的DeepSeek API Key；当前业务调用固定使用DeepSeek接口和`deepseek-chat` |
| `rag.mq.enabled` | 向量库和模型配置完成后填`true`，启用索引消息消费 |
| `rag.mq.topic` / `consumer-group` | `product-changed` / `product-index-consumer` |

索引每5分钟后台核对一次，也可登录管理员后调用 `POST /api/test/vectorstore/build`，再通过 `GET /api/test/vectorstore/status` 查看进度。模型未配置或向量服务故障时返回明确的关键词降级状态。更换Embedding模型或维度需要在新向量库重建，不能混用旧向量。

## 3. 中间件与应用启动

先准备MySQL并导入下节的demo库。其余中间件可按下面方式启动，命令从项目根目录执行，适用于PowerShell和macOS终端：

```sh
docker run -d --name tomatomall-redis -p 127.0.0.1:6379:6379 -v tomatomall-redis-data:/data redis:7.4.2 redis-server --appendonly yes
docker compose -f compose.orders.yml up -d namesrv broker
```

Redis容器已创建后使用 `docker start tomatomall-redis`。RocketMQ首次启动后创建两种Topic及消费组：

```sh
docker compose -f compose.orders.yml exec broker sh /home/rocketmq/rocketmq-5.3.2/bin/mqadmin updateTopic -n namesrv:9876 -c DefaultCluster -t order-timeout -a "+message.type=DELAY"
docker compose -f compose.orders.yml exec broker sh /home/rocketmq/rocketmq-5.3.2/bin/mqadmin updateSubGroup -n namesrv:9876 -c DefaultCluster -g order-timeout-consumer
docker compose -f compose.orders.yml exec broker sh /home/rocketmq/rocketmq-5.3.2/bin/mqadmin updateTopic -n namesrv:9876 -c DefaultCluster -t product-changed -a "+message.type=NORMAL"
docker compose -f compose.orders.yml exec broker sh /home/rocketmq/rocketmq-5.3.2/bin/mqadmin updateSubGroup -n namesrv:9876 -c DefaultCluster -g product-index-consumer
```

启动向量库前设置密码，二选一，并将同一密码填入后端配置：

```powershell
# Windows PowerShell
$env:RAG_PG_PASSWORD = "替换为你的数据库密码"
```

```sh
# macOS / Linux
export RAG_PG_PASSWORD='替换为你的数据库密码'
```

```sh
docker compose -f compose.rag.yml up -d
```

该配置创建用户`tomatomall`、数据库`tomatomall_vectors`，首次启动自动执行 [init.sql](../infra/rag/init.sql)。Redis、MQ、PostgreSQL使用Docker命名卷持久化；日常停止用`docker stop`／`docker compose stop`，不要使用`down -v`删除数据卷。首次初始化后修改密码环境变量不会自动更改库内用户密码。现有Compose是中间件配置，不包含后端、前端或完整商城一键初始化。

先启动后端，再另开终端启动前端：

```sh
cd tomatoMall-backend
mvn clean verify
java -jar target/TomatoMall-0.0.1-SNAPSHOT.jar
```

```sh
cd tomatoMall-frontend
npm ci
npm run dev -- --host localhost --port 5173 --strictPort
```

访问 `http://localhost:5173/login`。修改配置后重新打包并重启后端。上述方式读取打包在JAR里的`application.yml`；若选择外部配置，使用 `--spring.config.location=file:外部配置文件路径`，不要混淆两种配置来源。

## 4. demo数据库位置与迁移

现有源库：`127.0.0.1:33077/tomatomall_demo`，在原Mac电脑上，用户`root`、密码为空；数据目录 `/private/tmp/tomatomall-mysql-isolated`。应尽快导出备份，迁移使用SQL，**不要跨系统直接复制此数据目录**。仓库中的历史 `tomatomall.sql` 不代表当前demo库。

停止源后端写入后，在仓库外的备份目录执行（空密码提示时直接回车）：

```sh
mysqldump -h 127.0.0.1 -P 33077 -u root -p --single-transaction --quick --no-tablespaces --set-gtid-purged=OFF --default-character-set=utf8mb4 --result-file=tomatomall_demo.sql tomatomall_demo
```

将SQL复制到Windows／其他电脑，在目标MySQL创建**空的新库**，从SQL所在目录导入：

```sh
mysql -h 127.0.0.1 -P 3306 -u root -p -e "CREATE DATABASE tomatomall_demo CHARACTER SET utf8mb4;"
mysql -h 127.0.0.1 -P 3306 -u root -p --default-character-set=utf8mb4 -D tomatomall_demo -e "source tomatomall_demo.sql"
```

`--result-file`避免PowerShell输出重定向改变SQL编码。导入后修改后端连接配置，验证登录和商品列表。SQL包含结构和数据，不包含数据库用户权限、支付密钥及其他中间件状态；向量库可以根据MySQL重新生成。数据库备份不提交Git。这里提供迁移步骤，不代表已生成备份文件。

## 5. 支付宝沙箱配置

从 [支付宝沙箱控制台](https://open.alipay.com/develop/sandbox/app) 获取：

| Spring属性 | 内容 |
| --- | --- |
| `alipay.app-id` / `seller-id` | 沙箱APPID／沙箱商家PID |
| `alipay.private-key` | 应用私钥（Java格式，完整单行） |
| `alipay.alipay-public-key` | 支付宝公钥，注意不是应用公钥 |
| `alipay.server-url` | `https://openapi-sandbox.dl.alipaydev.com/gateway.do` |
| `alipay.charset` / `sign-type` | `UTF-8` / `RSA2` |
| `alipay.return-url` | `http://localhost:8080/api/orders/returnUrl`，浏览器返回地址 |
| `alipay.notify-url` | 支付宝可访问的公网HTTPS地址 + `/api/orders/notify` |

付款使用沙箱买家账号及支付密码。`return-url`不能代替验签后的异步通知；公网`notify-url`未连通时，不能保证付款后商城即时更新状态。

现有沙箱账号信息保存在Git忽略的 `tmp/local-demo/测试账号与沙箱配置.md`，现有运行配置在同目录`application.properties`；换电脑需私下迁移配置或重新申请，不会随Git同步。若重新建库却复用原沙箱APP，当前自增订单号可能与历史支付宝交易重复，应使用完整demo迁移或独立沙箱环境，并检查待支付订单与待投递消息。
